# dev-project

This folder is the shared workspace on your Desktop. Open **this directory** in Cursor so search, Git, and paths all refer to one project instead of your whole user profile.

## Open in Cursor

1. **File → Open Folder…**
2. Choose: `Desktop\dev-project` (under OneDrive if you use it: `OneDrive\Desktop\dev-project`)

Or from a terminal:

```powershell
cursor "C:\Users\pravi\OneDrive\Desktop\dev-project"
```

(If the `cursor` CLI is not on your PATH, use **File → Open Folder** instead.)

## Layout

- `src/` — application code (add frameworks or files here as we build).

## Older projects

Your previous apps (for example under `C:\Users\pravi\`) stay where they are. We can copy or link pieces into `src/` when you want them in this workspace.
